# Gestión Digital de Información para NicaTrade International

## Objetivo
Organizar información relacionada con una operación de importación desde México hacia Nicaragua utilizando diferentes herramientas digitales.

## Herramientas
- Word
- Excel
- PowerPoint
- Google Drive
- Simulación de gestión documental con Google Drive
- GitHub

## Flujo
**Crear → Procesar → Comunicar → Organizar → Compartir → Controlar → Buscar → Recuperar**

## Resultados
- 50 productos registrados
- Importe total: US$40,359.00
- Precio promedio: US$7.74
- Importe de productos de México: US$36,919.50
- Mayor importe: Mochilas (MEX-043), US$1,912.50

## Estructura
- `01_Word`: informe ejecutivo
- `02_Excel`: análisis de importación
- `03_PowerPoint`: presentación
- `04_Gestion_Documental`: repositorio documental
- `05_GitHub`: README
- `06_Evidencias`: guía para capturas reales
