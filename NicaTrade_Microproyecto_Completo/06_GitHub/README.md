# NicaTrade International

## Gestión Digital de Información

NicaTrade International desarrolla actividades de importación y exportación de productos de consumo. Este proyecto analiza una operación de importación desde México hacia Nicaragua y organiza la información utilizando herramientas digitales.

## Resultados del caso

- Importe total: US$40,359.00
- Precio promedio: US$7.74
- Productos registrados: 50
- Importe de productos de México: US$36,919.50
- Producto con mayor importe: Mochilas (MEX-043)
- Importe del producto de mayor valor: US$1,912.50

## Herramientas utilizadas

Microsoft Excel se utilizó para organizar y procesar la base de datos, calcular importes y clasificar los registros.

Microsoft Word se utilizó para desarrollar el informe ejecutivo y documentos comerciales.

Microsoft PowerPoint se utilizó para comunicar visualmente los resultados de la operación.

La gestión documental se estructuró mediante las áreas Administración, Clientes, Proveedores, Reportes y Ventas.

GitHub funciona como repositorio digital del proyecto y permite conservar una estructura organizada de los archivos y registrar cambios.

## Flujo de información

Crear → Procesar → Analizar → Comunicar → Organizar → Compartir → Controlar → Buscar → Recuperar.

## Conclusión

La integración de herramientas digitales permite organizar la información empresarial de NicaTrade International, facilitar el análisis de la operación de importación y mejorar la comunicación entre las áreas involucradas. La estructura documental proporciona una referencia común para conservar y recuperar información comercial.
